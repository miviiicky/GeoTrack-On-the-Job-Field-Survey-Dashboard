# GeoTrack: On-the-Job Field Survey Dashboard

## 📌 Project Overview
This project is an interactive Web GIS Dashboard developed as part of my 15-day **On-the-Job Training (OJT)** and field survey experience. The primary objective of this dashboard is to effectively visualize, manage, and analyze spatial data collected directly from the field on a web platform.

* **Live Web Map Link:** [Click Here to View the Dashboard]([https://miviiicky.github.io/GeoTrack-On-the-Job-Field-Survey-Dashboard/](https://onkar-geoleneinfo.github.io/GeoTrack-On-the-Job-Field-Survey-Dashboard/))

## 🛠️ Technologies & Tools Used
* **GIS Software:** QGIS (Quantum GIS) for spatial data processing, attribute management, and map styling.
* **Web GIS Tools:** `qgis2web` plugin for converting and exporting GIS layers into web-ready formats.
* **Frontend Libraries:** HTML5, CSS3, and JavaScript mapping frameworks (Leaflet / OpenLayers).
* **Hosting & Deployment:** GitHub Pages for live web hosting.

---

## 🚀 Key Features of the Dashboard
* **Interactive Map Navigation:** Smooth zoom in, zoom out, and panning capabilities to explore the surveyed region.
* **Layer Layer Control:** Fully interactive layer switcher allowing users to toggle different vector layers (Points, Lines, Polygons) on and off.
* **Pop-up Information:** Clickable map features that display detailed attribute data captured during the field survey.
* **Responsive Layout:** Optimized to load and function smoothly across both desktop and mobile web browsers.
